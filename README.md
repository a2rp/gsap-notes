# GSAP Study Notes

These are my personal study notes from learning and working with GSAP. They bring together the JavaScript animation concepts, examples, timing patterns, scroll interactions, and React practices I want to keep as a practical reference.

## About these notes

I am building this collection as I study GSAP and use it in interface work. The notes focus on core concepts first, explain the reason behind each API, and use small JavaScript examples that can be adapted to real pages.

The core package is installed from npm. Optional plugins are introduced only where they solve a clear animation problem. React examples use the official GSAP React integration and show how to scope and clean up animations.

## Core topics

- Install GSAP and create a first tween
- Select animation targets and configure values
- Control duration, delay, repeat, and callbacks
- Choose eases and coordinate timelines
- Use stagger, labels, and timeline positions
- Animate CSS properties and SVG elements
- Build scroll-based motion with ScrollTrigger
- Adapt animations to screen size and user input
- Scope and clean up animations in React
- Respect reduced motion and test real interfaces

## Suggested setup

Start a JavaScript project with a modern build tool, then install GSAP with npm:

~~~sh
npm install gsap
~~~

Import only the package features needed by the project. Read each chapter in order or use the index to find the concept needed for the current task.
